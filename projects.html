Inequality in academia from a Network Science perspective

In this project, we decided to focus on a preferential attachment, majority/minority network with vertex removals. We use the definitions of power inequality and glass ceiling provided by Avin et al, and checked whether these emerge in our simplistic model already. This model is inspired by real world scenario of academic and citation networks, which have consistently observed inequality, particularly in STEM fields. It is essential to study these keeping in mind vertex removals, which are very prominent and vastly alter the system. We have observed (in data from 2000 to now) that the academic collaboration network in a slowly evolving network, where number of people who join is only slightly higher than those who leave. The model parameters we focus on are p (probability that a node is added at a time step), f (proportion of minority) and r (rate of removal of minority). A combination of these parameters provide interesting results in inequality analysis. We hope that some of these results can be used to derive conclusions about which parameter has to be changed to improve condition of minority in the network (for eg, increasing p is beneficial for minority even when f is low).

Opinion dynamics with advantage to one opinion

We consider a network, where each vertex has one of two opinions. At every time step, a new node enters the system and connects with existing vertices with preferential attachment. Suppose it connects to k nodes of opinion 1, then the node chooses opinion 1 with probability k/m. What happens when we let this process run forever? Is there convergence of any one type? This model was studied by Antunovic et al, where they proved the existence of limiting distributions which have full support on [0,1], have no atoms (in the linear case). We are currently considering a slight adaptation of this model, what if nodes of type 1 are allowed to switch to type 2 with probability p? (This is a work in progress).

Error Correcting Codes and the Liar Game

The liar game is a two person game, where A thinks of a number that B has to guess in 20 yes/no style questions - and A is allowed to lie once. J Spencer developed an ingenious strategy to keep track of possible lies to give the sufficient conditions for the questioner to win. This has a direct connection to error correction! Every lie can be seen as an error in transmission. Thus, ideally any solution to the liar game can we converted to a one error correcting code. This is what we investigated in my thesis, where we adapted Spencers strategy to a code. We also studied the liar game when there is a continuous search space (for example, the interval [0,1]). Here player B would win if the get within epsilon distance.
